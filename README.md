# comercial

Processo comercial de vendas do escritório de contabilidade — do primeiro contato com o lead até a indicação de novos clientes.

## Como usar este repositório

1. Leia a **visão geral** para entender o funil completo.
2. Ajuste os campos marcados com `[AJUSTAR]` à realidade do escritório (preços, nichos, nomes, metas).
3. Use os **modelos** no dia a dia (mensagens, roteiros, proposta, checklist).
4. Revise mensalmente as **métricas** e atualize o processo.
